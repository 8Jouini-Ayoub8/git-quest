# >_ GIT QUEST · Securinets ENIT

> *Hack fast, defend faster.*

A hands-on, flag-based quest to learn **Git & GitHub** — workshop session 1/3.
A bot, the **Quest Master 🤖**, watches your fork and gives you a flag for every mission you complete:

```
SecurinetsENIT{md5...}
```

## 🚀 Start

1. Click **Fork** (top-right) → keep the name `git-quest` → **Create fork**.
2. Come back here → **Issues** → **New issue** → **🚩 Start the Quest**.
3. The Quest Master answers in your issue with your first mission. After each mission, comment **`/check`**.

## 🗺️ The map

| # | Mission | You'll learn |
|---|---------|--------------|
| 0 | 🍴 Enlist | `fork` |
| 1 | 🆔 Identity | `clone` `config` `status` `add` `commit` `push` |
| 2 | 👻 Ghost in the History | `log` `show` |
| 3 | 🎯 Precision Strike | `status` `diff` `add <file>` |
| 4 | ☁️ Teammate in the Cloud | rejected push, `pull` |
| 5 | 🌿 Branch Out | `branch` `switch` `merge` `push -u` |
| 6 | 📡 Intel from HQ | `remote` `fetch` + a merge **conflict** |
| 7 | ⚙️ Wake the Machine | GitHub Actions, CI logs |
| 8 | 📨 Report to HQ | **Pull Request** |
| ⭐ | 🚀 Go Live (bonus) | deployment with GitHub Pages |

## 🧰 Before you start

- Git installed: `git --version` (Windows: [git-scm.com](https://git-scm.com) — use **Git Bash**)
- A GitHub account, signed in
- First push asks for credentials? Use the browser login window (Git Credential Manager) — **not** your GitHub password.

## 📜 Rules

- Your flags are computed from your username: copying someone's flag gives nothing. 😉
- Don't try to fool the bot by editing workflow files — it checks.
- Help each other by **explaining**, not by typing on someone else's keyboard.
